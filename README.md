# Experiência Prática 4: Monitoramento Estrutural de Ponte Estaiada

Este repositório contém os registros, análises e diagramas desenvolvidos durante a Experiência Prática 4 da disciplina de Integração e Análise de Dados em Sistemas de Engenharia (Engenharia Civil - Universidade Cruzeiro do Sul).

## 📌 Objetivo do Projeto
O projeto consistiu na análise de dados e monitoramento de integridade estrutural de uma ponte estaiada, correlacionando variáveis físicas ambientais com o comportamento dinâmico da estrutura para fins de manutenção preditiva.

## 📊 Análises Realizadas
* **Tratamento de Dados (ETL):** Higienização de dados de sensores, remoção de outliers e correção de inconsistências temporais.
* **Correlação de Variáveis:** Análise do impacto da oscilação da temperatura externa na variação da frequência natural da estrutura da ponte.
* **Arquitetura de IA:** Modelagem do fluxo de dados (Entrada, Processamento e Saída) para um sistema inteligente de diagnóstico preditivo.

## 📁 Evidências do Projeto
As imagens geradas durante os experimentos foram organizadas na raiz do projeto e demonstram os seguintes cenários:
1. **Gráfico de Monitoramento:** Correlação temporal entre Frequência Natural vs. Temperatura.
2. **Diagrama do Sistema:** Arquitetura lógica do agente inteligente de monitoramento.
